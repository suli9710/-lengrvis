# 合规认证路线（SOC 2 / ISO 27001 Roadmap）

**版本**：v0.1（草稿）  
**最后更新**：2026-06-22  
> 状态口径：fail-closed。**当前未持有任何安全/合规认证。** 本文件为规划，不得对外宣称"已认证"或"合规"。

## 1. 现状

- 无 SOC 2、无 ISO 27001、无第三方渗透测试报告。
- 已具备的基础：审计链（HMAC）、审批边界、脱敏中间件、依赖与密钥扫描、安全回归门禁、隐私擦除端点（均有部分测试证据，见 `pipl-gdpr-checklist.md` 与 `security-whitepaper.md`）。

## 2. 触发条件

以下任一发生时启动正式认证流程：

- 面向企业/Team 客户的商业销售启动；
- 引入云端账户体系或托管服务；
- 关键采购方在合同中要求认证。
