# Lengrvis 用户手册（快速上手 + FAQ + 故障排查）

> 适用范围：Windows 桌面版（当前唯一 Supported 平台）。Android 伴侣为 Preview。
> 本手册覆盖从安装到完成第一个任务；高级配置面向开发者，普通用户不需要编辑 `.env` 或 `config.yaml`。

## 1. 快速上手（10 分钟完成第一个任务）

### 安装与启动

1. 解压 portable 包（或 zip/自解压包）到任意目录。
2. 双击 `启动 Lengrvis.cmd`（排障时用 `Start-Lengrvis-Debug.cmd`，会保留控制台日志）。
3. 首次启动会初始化本地数据目录；所有数据存在本机，不会自动上传。

### 完成第一个任务

首屏提供 5 个任务模板，每个模板都标注了本机处理范围、云端边界、是否需要审批、预计耗时：

| 模板 | 说明 | 是否写入 |
| --- | --- | --- |
| 检查电脑状态 | 只读系统诊断，最适合第一次体验 | 否 |
| 查找大文件 | 扫描指定目录找出占用空间的文件 | 否 |
| 总结本地文档 | 选择一个文档生成摘要 | 否 |
| 文档问答 | 对本地文档提问，回答带来源引用 | 否 |
| 整理下载目录 | 给出整理计划，执行前需要你审批 | 是（审批后） |

建议第一次点"检查电脑状态"：它无需任何配置、不写入任何文件，几秒内在 Task Workspace 给出可读结果。

### 选择模型模式（设置 → 模型）

- **快速（efficiency）**：使用你配置的云端模型，体验最流畅。
- **隐私（privacy）**：全部本机处理；没装本地模型时会明确失败并给出安装引导，**不会静默切到云端**。
- **智能混合（hybrid）**：敏感内容留在本机，其余走云端。

设置页提供本地模型健康检查和 Ollama 安装/启动/拉取推荐模型的入口，并显示模型大小、硬件要求和速度预估。

### 手机伴侣（Preview）

设置 → 移动配对：桌面显示二维码 → 手机 App 扫码配对（需同一局域网）。配对后手机可接收审批请求、查看任务进度、申请短期远程输入授权。注意：局域网非 loopback 连接要求 WSS/证书信任，纯 HTTP 会被拒绝，这是刻意的安全边界。

## 2. FAQ

**Q：我的数据会上传吗？**
默认不会。任务、对话、索引、录屏全部存在本机 SQLite。只有 efficiency/hybrid 模式下，任务文本会发送给你自己配置的云端模型服务商。无任何云端遥测。

**Q：危险操作会不会直接执行？**
不会。所有操作按 R0-R4 分级：R3/R4 高危操作默认拒绝或要求审批；删除/写入类操作执行前展示预览并等待你确认；文件删除走回收站（send2trash）。

**Q：如何删除我的全部本地数据？**
当前通过 API：`POST /api/system/privacy/erase-local-data`（body 传 `{"confirm": "erase-local-data"}`）。会删除任务、对话、录屏、配对、索引和已导出诊断包，保留防篡改审计链并记录删除事件。设置页按钮入口在路线图上。

**Q：任务录屏是默认开启的吗？**
否。默认完全不采集；只有显式设置 `LENGRVIS_TASK_RECORDING_ENABLED=true` 才会在本机记录，且公开接口只返回脱敏摘要，不返回原始截图。

**Q：为什么隐私模式下任务失败了？**
隐私模式要求本地模型可用。失败信息会给出修复路径（安装/启动 Ollama、拉取推荐模型）。这是有意设计——隐私模式宁可失败也不偷偷用云端。

## 3. 故障排查

| 症状 | 处理 |
| --- | --- |
| 双击启动后窗口没出现 | 用 `Start-Lengrvis-Debug.cmd` 启动查看控制台输出；检查 `logs/` 目录最新日志 |
| 提示端口被占用 | 启动器会提示占用进程；关闭占用程序后重试（启动器不会强杀别的程序） |
| 后端连接失败（首屏离线提示） | 等待数秒自动重连；持续失败时重启应用，再看日志目录 |
| 手机扫码配对失败 | 依次确认：手机和电脑在同一网络 → 桌面后端已启动 → 二维码未过期（重新生成）→ 非 loopback 连接需要 TLS/WSS 配置 |
| 本地模型不可用 | 设置 → 模型 → 本地模型健康检查，按提示安装/启动/拉取 |
| 需要向支持人员求助 | 设置 → 系统信息 → 导出诊断包（已脱敏：路径标签化、不含任务正文/密钥/设备名）；外发前仍建议自查内容 |

日志位置、数据目录位置：设置 → 系统信息 中可见，并有"打开日志位置"入口。
