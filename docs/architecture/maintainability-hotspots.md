This file maps high-complexity areas that should be split or given explicit ownership before broad release. It supports `RR-P1-001` in `docs/release/release-readiness-dashboard.md`.

## Hotspot inventory

source-size ranking before choosing the next split. The report prints source
file count, total source lines, p95 file size, the largest file, and per-area
line totals. Use `.venv\Scripts\python.exe scripts\check_source_size.py --json`
when recording trend snapshots in release evidence.
