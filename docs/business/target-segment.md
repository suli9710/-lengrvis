# 细分切入市场：定位一页纸（市场化清单 #26）

> 状态：内部定稿 v1（2026-06-10）。待完成：≥5 个目标用户访谈验证（未做，阻断对外投放）。

## 一句话定位

**给数据不能出门的专业人士的可审计本机电脑助手。**

## 首发细分人群

**首选**：隐私敏感的专业个人与小团队 —— 律师/律所、财务/会计师事务所、医疗从业者、研究人员。
共同点：日常被文件整理、文档摘要、资料检索消耗大量时间；但客户资料/病历/底稿**在合规上不允许投喂给云端 AI**。

**次选**：合规要求高的中小企业 IT —— 需要给员工配 AI 助手，但要求可审计、可自托管、策略可控。

**明确不打**：追求最强模型能力的极客（去用云端 Agent）、纯娱乐用户、大企业（销售周期撑不起）。

## 三条差异化主张

1. **数据不出门**：隐私模式全链路本机处理，不可用时明确失败、绝不静默回退云端（有自动化测试锁定该行为，不是宣传话术）。
2. **每一步可审计**：R0-R4 风险分级、危险操作审批+预览+回滚、HMAC 防篡改审计链——出了事能向合伙人/审计师举证"AI 做了什么、谁批准的"。
3. **可自托管、不绑平台**：无云端账户、无遥测；团队版策略与数据全部留在客户侧。不与微软/腾讯比平台分发，比的是"你的机器你做主"。

## 价值假设（待访谈验证）

| 假设 | 验证方式 |
| --- | --- |
| 律师/财务每周花 ≥3 小时做可被本品自动化的文件/文档工作 | 访谈 + 任务日志样本 |
| "本机处理"是他们选择工具的一票否决项 | 访谈定序：隐私 vs 能力 vs 价格 |
| 他们愿意为此支付 ¥299/年级别的价格 | 定价访谈 / 预售落地页 |

## 渠道假设

行业社群（律协/注会论坛）、合规主题内容营销、事务所 IT 服务商分销。不投通用流量。
