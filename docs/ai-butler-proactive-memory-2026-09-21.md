# 管家主动记忆重要信息

管家现在会在处理对话时提取少量有后续使用价值的信息，无需每次明确说“记住”。复用原 MemoryAgent、SQLite、来源校验和记忆管理界面，没有另建记忆库。

## 使用与边界

- 管家自动记忆默认开启，可在管家概览切换，也可说“关闭自动记忆”或“开启自动记忆”。它独立于事项统筹开关。关闭后仍可明确要求“记住：……”。原执行引擎的任务摘要自动学习设置保持原样。
- 自动提取接在现有管家规划模型调用中，每次最多三条。适用信息包括明确偏好、职责和项目背景。只分享信息时保存记忆即可；同时交代工作时，保存记忆后继续原事项。
- 本轮来源限新进入管家对话的用户消息和补充信息，不扫描旧聊天、不从网页或文件事件直接建立可信记忆。新字段有默认值，兼容旧事项。
- 明确陈述必须引用输入中完整的句子或行，保留否定、限定和归属，按原文保存。模型推断及与旧记忆冲突的内容进入“待审阅”，不参与正常召回；冲突审核后通过原版本链替代旧记忆。
- “不要记住”“仅限本次”等指令优先。密码、认证信息及操作授权不会通过自动记忆生效。长期记忆是参考数据，不能扩大操作权限。
- 已保存事实与偏好进入后续规划和执行上下文，本次明确要求优先。临时信息支持有效期；未确认推断默认 30 天。删除、撤销、过期及被替代的记录沿用原召回过滤。
- 保存记忆与记录事项已处理的信息指纹在同一事务完成，嵌入计算在事务外进行。重规划不会重复保存同一条提取证据，忘记后不会由这条旧证据重新建立。用户在新事项中重新提供信息属于新的输入。
- “我的记忆”显示自动保存及陈述/推断来源，支持审核、更正、撤销、忘记。更正通过 `supersedes` 创建新版本，旧版本显示为历史版本。所有新增数据进入原隐私清理范围。

## 验证

只新增三组后端定向验证和一个界面交互测试：保存与召回及遗忘、来源与关闭/秘密过滤、冲突审核与保存期间的版本变化，以及更正记忆提交替代关系。

- 相关后端测试：127 passed。
- 相关桌面测试：23 passed；两套 TypeScript 类型检查通过。
- 渲染器生产构建及包体积检查、Electron 编译通过。
- Chromium 组件交互：自动记忆开关、更正、历史版本展示、删除通过，无页面错误；IPC 替代记录 ID 校验通过。
- 截图：`.tmp/audit-fixes/butler-auto-memory-overview.png`、`butler-auto-memory-management.png`。

定向验证为受控规划输出，证明保存、恢复与界面链路。现有真实模型服务仍未接通，因此未验证真实模型对“哪些信息重要”的提取质量和误记率，不把受控测试视为真实模型验收。
