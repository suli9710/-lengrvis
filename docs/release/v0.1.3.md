# Lengrvis 0.1.3 发布说明（草稿，待发布）

本版本整合 v0.1.2 之后的仓库更新，以及 2026-11-01 工作区中的桌面任务流程、后端重构和安全修复。Windows 开发预览包已构建并完成下列本地检查，现以草稿供审阅；正式候选证据及发布签收尚未完成。

## 主要变化

### 桌面任务体验

- 首页优先展示输入、当前任务、最近任务与成果核验状态；简化首屏和导航，保留可收起的小马办公室及角色入口。
- 审批进入主导航，待审批时显示“需要你确认”；保留风险、操作对象、预览和有效期，减少重复提交并在提交时重新检查有效期。
- 首页与对话草稿在当前窗口会话中保留，发送失败时不覆盖用户的新输入；确认删除本机数据成功后同步清除草稿。
- 文档入口可直接打开文件选择；进度页直接展示成果，任务切换时忽略旧请求返回，读取失败可重试。
- 调整窄窗口布局、字号、对比度、焦点和控件标签；修复首次启动与浏览器活动界面的懒加载等待问题。

### 后端可靠性与数据保护

- 拆分上下文管理与任务服务模块，保留原有调用入口，整理压缩、摘要、会话及引擎桥接职责。
- 数据库升级前创建加密快照，保留最近三份；快照验证在只读内存数据库中完成，隐私清除同步删除数据库备份。
- 加入打包 Python 和实际后端可执行文件的 SQLite 运行时检查；构建及发布启动拒绝存在已知 WAL-reset 缺陷的 SQLite 版本。
- 保留已观察到的内容来源，在派生结果、危险操作及审批边界检查来源是否丢失；加强回滚、文件路径与备份身份校验。
- 收紧 Electron 内容安全策略、桌面 IPC、WebSocket 和截图路径处理，减少非预期本机端点及路径访问。

### 兼容性与交付

- MCP 明确支持 `2025-11-25` 协议；不支持的协议版本在联网或启动子进程前被拒绝。
- 更新桌面、移动端和 Python 依赖及锁文件，完善 React 19 构建体积检查、Expo/Android 构建兼容性和 Windows 原生工具身份校验。
- 实际模型评测报告分别记录执行阶段符合情况、已声明后态验证、耗时及用量/成本覆盖率；这些字段本身不代表真实模型质量已验收。
- 完善候选产物、检查证据与提交身份的绑定，以及后续审核和发布验证流程。

- 后端：关键功能分组验证为 218 项通过及另组 282 项通过；构建环境数据库、隐私、打包与版本检查 119 项通过。首轮混合顺序遇到既有 run API 模拟任务残留引起的 3 项隐私测试失败，隔离运行通过；不声称单次全量回归通过。修改文件 Ruff lint 与格式检查通过。

- `verify_packaging.ps1 -RunExecutableSmoke -SmokeTimeoutSeconds 45` 通过：结构、无 source map、默认包不捆绑模型，以及独立/便携后端隔离 `/health` 探测均通过。这不等于干净机器或真实任务结果验收。

## 已知边界

- 当前仍为开发预览范围；签名与发布准入状态必须在分发前明确记录。未签名产物不具备 Windows 发布者身份验证。
- 本地模型运行时与模型不默认内置，下载、安装和离线任务能力需要针对最终构建单独验证。
- 数据库快照加密不等于主数据库全文加密；恢复工具提供完整性检查，不会覆盖在线数据库或自动恢复历史授权。
- MCP `2026-07-28`、旧版 HTTP+SSE 传输及完整 OAuth 生命周期不属于当前兼容性承诺。
- Android companion 继续为 Preview；版本信息同步不代表已提供 APK、完成真机 LAN/WSS 验收或获得商店分发签收。
- 界面显示本机版本及本地发布说明；没有据此宣称完整的在线自动更新、崩溃上报或公开安全的诊断包分享流程。
