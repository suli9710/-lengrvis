## 1. 概述

Lengrvis（以下简称"本软件"）是一款以本地处理为核心的桌面 AI 助手软件。我们高度重视您的隐私。本政策说明本软件收集、使用、存储和共享个人信息的方式。

**核心原则：您的数据始终留在您的设备上。**

本软件默认在您的本地计算机上运行所有 AI 推理、文件操作和屏幕感知任务。除您明确开启的功能（见下文）外，您的数据不会被发送至任何外部服务器。

## 3. 数据收集与处理详情

### 3.1 本地处理数据（始终在您的设备上）

| 数据类别 | 说明 | 存储位置 | 是否离开设备 |
|---|---|---|---|
| 对话与任务记录 | 您与 AI 的对话内容、任务执行结果 | 本地 SQLite 数据库 | 否 |
| 文件索引 | 本地文件名、路径的索引快照（不含文件内容） | 本地索引数据库 | 否 |
| 屏幕感知数据 | 当前活动窗口标题、应用上下文（不含截图持续存储） | 内存中，关机即清除 | 否 |
| 操作审计日志 | 工具调用记录、审批记录、安全事件（HMAC 签名链） | 本地审计数据库 | 否 |
| 账户与配对信息 | 移动端配对 Token、设备指纹（仅本地校验用） | 本地密钥存储 | 否 |

### 3.2 可选遥测数据（仅在您明确启用时收集）

本软件提供**匿名遥测**功能，默认关闭。启用后，以下数据将发送至 Sentry（崩溃报告）或自建收集端点：

| 数据类别 | 说明 | 是否可识别个人 |
|---|---|---|
| 崩溃堆栈 | 程序异常时的调用栈与错误信息（已脱敏） | 否 |
| 功能使用统计 | 首次启动成功率、模型安装成功率等聚合指标 | 否 |
| 设备类型与 OS 版本 | 操作系统名称与大版本号（如 Windows 11、macOS 14） | 否 |

您可以随时在「设置 → 隐私 → 匿名遥测」中关闭此功能。关闭后不会发送任何遥测数据。

### 3.3 云端 LLM 调用数据（仅在您选择云端模型时）

如果您选择使用云端 LLM 服务（如 OpenAI API），对话内容将发送至对应服务商进行处理。此过程受对应服务商的隐私政策约束。本软件本身不在此过程中存储或中转您的对话内容。

### 3.4 移动端远程控制数据

当您启用移动端远程控制功能时：

- 配对过程在**局域网/Wi-Fi**内进行，配对码为一次性 16 位十六进制令牌
- 远程操作指令通过**点对点加密通道**传输，不经过任何中间服务器
- 远程操作需经桌面端**用户明确审批**后方可执行
- 所有远程操作均记录在本地审计日志中

## 4. 数据存储与安全

- 所有本地数据存储于用户个人目录下的加密数据库中（Windows 使用 DPAPI，macOS 使用 Keychain 保护密钥）
- 本地数据库文件权限设置为仅限当前用户访问（Unix 0600 / Windows ACL）
- 审计日志采用 HMAC 哈希链防篡改机制
- 桌面端 API 通信限定在环回地址（127.0.0.1 / localhost），不接受外部网络请求

---

## 5. 数据共享

我们**不会出售、出租或交易**您的个人信息。

在以下情形中，数据可能被有限共享：

- **您主动选择的云端 LLM 服务商**：仅限您当前对话内容，由对应服务商按其政策处理
- **崩溃报告服务（Sentry）**：仅限您启用遥测后的匿名崩溃数据
- **法律法规要求**：在法律强制要求或为保护合法权益时，依法披露必要信息

## 6. 数据可携权

您可通过「设置 → 数据 → 导出」将本地所有数据导出为 JSON 格式文件，包含：对话记录、任务历史、审计日志、技能配置。

---

## 7. 数据删除权

您可通过以下方式删除数据：

- **一键清除**：「设置 → 隐私 → 清除本地数据」将永久删除所有本地存储的对话、任务、索引和审计记录
- **卸载清除**：卸载本软件时，安装程序提供清除所有本地数据的选项
- **数据最小化**：本软件默认不保留任何云端用户数据，无需远程删除请求

---

## 8. 未成年人保护

本软件面向成年用户，不面向 14 岁以下未成年人。我们不故意收集未成年人个人信息。如发现误收集，请联系我们删除。

---

## 9. 跨境数据传输

- **本地模式**：无跨境传输发生
- **云端模型模式**：若您选择使用海外 LLM 服务商，对话内容将传输至服务商所在国家/地区。此传输受服务商隐私政策约束
- **遥测模式**：Sentry 数据可能传输至其服务器（美国/欧洲），但数据为匿名聚合，不含可识别信息

您在选择云端模型或启用遥测时，即视为知悉并同意跨境传输。

## 11. 您的权利

根据适用法律（包括 GDPR 和 PIPL），您享有以下权利：

- **知情权**：了解数据如何被处理（本政策即为此服务）
- **访问权**：通过数据导出功能查看所有本地数据
- **更正权**：直接修改本地数据或联系开发者协助
- **删除权**：通过一键清除功能删除数据
- **可携权**：通过导出功能获取数据副本
- **拒绝权**：关闭遥测、关闭云端模型功能
- **撤回同意权**：随时关闭已启用的可选功能，已收集的数据保留在本地可随时清除
