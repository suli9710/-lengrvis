# 退款政策（Refund Policy）

**版本**：v0.1（草稿）  
**状态**：**支付系统尚未上线**——本政策在接入支付渠道（Stripe / Paddle 等）、吊销/降级流程通过商业闭环证据验收，并开放付费购买后生效。

---

## 1. 适用范围

本政策适用于通过官方支付渠道购买的 Lengrvis 付费许可（Pro / Max 等）。免费版不涉及退款。

## 2. 冷静期退款（14 天）

- 自**首次成功付费之日**起 **14 个自然日**内，可申请全额退款。
- 退款获批后，对应订阅 key 将停止继续激活；已安装的离线许可证需要通过签名吊销清单、换发许可证或经审核的在线同步流程完成降级。
- 在在线吊销同步通过发布门禁前，不承诺退款后所有离线安装会实时或自动停用。客户或管理员完成吊销清单/替换许可证部署后，相关付费功能会按许可证状态回退。
- 退款原路返回至原支付方式；到账时间取决于支付渠道与发卡行（通常 5–10 个工作日）。

## 3. 不适用退款的情形

- 超过 14 天冷静期的已生效订阅周期。
- 已明显超出评估目的的滥用性使用（例如批量短期购买退款套利）。
- 违反 EULA 被终止许可的账户。
- 第三方 LLM provider 的用量费用（由用户与该 provider 直接结算，不在本政策内）。

## 4. 订阅续费

- 订阅在每个周期开始时扣费。可随时取消，取消在**当前周期结束时**生效，已支付的当前周期默认不退款（冷静期除外）。
- 支付系统上线后，续费日期与金额必须在购买页、订单/收据或账户材料中可见；上线前不得对外承诺自动续费或账户自助管理能力。

## 6. 与法定权利的关系

本政策不影响您在适用消费者保护法（含中国《消费者权益保护法》、欧盟消费者权利指令等）下享有的法定退款/撤回权；冲突时以法定权利为准。
