# 服务等级协议（Service Level Agreement, SLA）

**版本**：v0.1（草稿）  
**状态**：**生效条件未满足**——当前产品处于发布前阶段，无公开托管的云端服务，本 SLA 暂不适用。

---

## 0. 适用边界（重要）

Lengrvis 为本机优先软件。**本机运行的功能不在任何 SLA 覆盖范围内**——其可用性取决于用户自有设备，许可方无法也不对此承诺可用率。

本 SLA 仅在许可方**实际对外提供托管云端组件**（如云端账户、托管遥测端点、云端协作中转）且客户为之**付费**时生效。在该前提满足前，本文件仅为目标基线，不构成承诺。

## 1. 可用性目标（生效后）

| 套餐 | 月度可用率目标 | 计量对象 |
| --- | --- | --- |
| Pro（云端组件） | 99.5% | 托管 API 端点成功响应率 |
| Team / 企业（云端组件） | 99.9% | 托管 API 端点成功响应率 |

可用率 =（计费周期总分钟数 − 不可用分钟数）/ 计费周期总分钟数 × 100%。

## 2. 排除项

以下情形不计入不可用时间：

- 计划内维护（提前至少 48 小时通知，每月累计不超过 4 小时）。
- 客户侧网络、设备、配置或第三方 LLM provider 故障。
- 不可抗力（自然灾害、大规模网络故障、政府行为等）。
- 客户违反 EULA 或滥用导致的中断。
- 本机功能（按第 0 条不在覆盖范围）。

## 3. 服务积分（生效后）

| 月度实际可用率 | 服务积分（按月费比例） |
| --- | --- |
| 低于目标但 ≥ 99.0% | 10% |
| 99.0% 以下但 ≥ 95.0% | 25% |
| 低于 95.0% | 50% |

- 服务积分为**唯一且排他**的可用性补救方式，以账户抵扣形式发放，不折现。
- 客户须在事件发生月结束后 30 日内提交带证据的申请。

## 4. 支持响应目标

| 严重级 | 定义 | 首次响应目标 |
| --- | --- | --- |
| P1 | 云端组件完全不可用 | 4 小时（Team）/ 1 工作日（Pro） |
| P2 | 主要功能受损但有变通 | 1 工作日 |
| P3 | 一般问题/咨询 | 3 工作日 |
